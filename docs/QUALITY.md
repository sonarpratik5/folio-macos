# Quality and limits

- Q1: PDFKit serialization is not a full-fidelity guarantee for arbitrary PDFs, signatures, forms, embedded fonts or existing third-party annotations. Tests cover only generated fixtures and preserve the source. Unchanged foreign annotation objects are retained; relative layering against edited objects and rich third-party FreeText/callout metadata need broader verification. Imported supported markup can be edited/erased intentionally; links/widgets/foreign stamps are excluded from hit targets. Add a synthetic fidelity matrix before broad export claims.
- Q2: Multi-column/rotated/cropped/non-Latin and cross-page selection geometry needs interaction testing. Scanned PDFs need OCR, which is absent. Core tools now select/recolor/edit/erase supported annotations; Undo remains session-only. Fixture geometry covers crop/rotation in page space; the full rotated/cropped interaction matrix is still needed. Text longer than its available page region remains in Contents but may be clipped visually.
- Q3: Manifest and PDF writes are individually atomic, not a cross-file transaction. Import rollback handles manifest failure; a crash between copy and manifest can leave an orphan. Editor drafts are saved on normal reader transitions/quit but are not crash-recovery drafts. No version history, migration beyond schema rejection or multi-process coordination. Do not run concurrent app instances against the same library.
- Q4: PDF loading, explicit Find, thumbnail generation, annotation encoding and all-library note scanning run on the main actor. History retains annotation snapshots including pasted PNG bytes for the session. Large libraries/papers may pause the UI. No bounded async repository or thumbnail cache yet. Metadata is saved on page changes without coalescing.
- Q5: Minimum window size is 960×640; toolbar scrolls if space is tight. VoiceOver, full keyboard focus, split-pane restoration and all display-scale combinations need a broader audit. Dark mode affects chrome, not PDF contents. One glass-inspired theme replaces design presets; it uses native materials rather than claiming exact Liquid Glass parity on every supported OS.
- Q6: Local app is ad-hoc signed, unsandboxed and unnotarized. No App Store entitlements, security-scoped bookmark persistence, automatic updates, universal binary or Finder file associations configured. Packaging is for development on the build machine.
- Q7: No web-data migration. Export browser annotations to PDFs first where supported; browser-local stars/chats/drafts will not appear automatically. Reimports create separate copies. There is no native delete-library-entry action yet.
- Q8: Home AI implements chat, selected explanation, saved three-card overview, paper/web tools and provider choice, but not streaming, rendered LaTeX, OpenReview discovery/analysis or concept graph refinement. No arXiv import, note-image attachments or writing extensions. Pasted on-page image stamps are supported. [PORTING](PORTING.md) is authoritative for parity.
- Q9: AI tests use fake providers, generated PDFs and disposable processes, not live account/model access. Codex CLI flags/model availability and Claude model/web-tool access depend on installed versions/accounts; unavailable choices fail without fallback. Launch-environment setup has no credential entry form. PDF text extraction occurs on the main actor and may pause large documents; OCR/equation fidelity and full-paper coverage are not guaranteed. Answers display after completion. Text fingerprints intentionally block reusing old AI files after paper text changes; there is no migration/recovery UI for that case yet.

Verification belongs in [TESTING](TESTING.md). Open quality items are context, not automatic authorization to work on them.

## Limits added 2026-11-14

- Q10: No interactive GUI QA of the new reader, margin marks (especially with rotation, which relies on workspace refresh), drag-drop, arXiv download, notes inspector or streaming. Design was seen only in offscreen ImageRenderer snapshots of Library/empty/Reviews/Concept Map.
- Q11: LaTeX is shown as Unicode text, not typeset. Codex CLI has no streaming. Live AI providers unverified.
- Q12: Writing pages are blank ruled PDF pages; no web writing-space layout parity. Arbitrary third-party PDF fidelity remains unverified. Q7/Q8 are superseded where they say no library removal, arXiv, note images or concept graph.
