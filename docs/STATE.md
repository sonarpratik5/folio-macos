# Current state

Native macOS starter, created 2026-11-14. SwiftUI window/navigation/settings and AppKit panels wrap PDFKit directly. No browser wrapper, authentication or server.

- Library: managed-copy PDF import; list/grid views; title and written-note search; recent/title sort; continue reading; paper/notes/saved-page totals; All documents/Opened/Insights/Notes/Starred pages. Stars and written notes link directly to their PDF page. Paper details show position/stars/notes with Resume and Ask Folio. Every import opens the paper, so Opened contains all imports. Library Ask opens the paper with the Ask panel; Insights preserves the current reader.
- Reader: continuous vector PDF rendering, native selectable text, page list, embedded outline, page-number input/previous/next, auto-fit and manual zoom, explicit whole-PDF Find with match navigation. Initial resume position and subsequent page changes save locally.
- Annotations: persistent Select/Highlight/Underline/Text/Note/Eraser tools; select-first marking also works. Per-line, cross-page marks form one group and one history entry. Select marks to recolor, attach a written note or delete. Text uses editable FreeText with size/color, on-page movement and a resize handle; note pins open a small editor, and selected passages can become one quoted note across pages. Clipboard images paste as editable, movable/resizable standard stamps with saved appearances. One eraser drag is one Undo. Explicit Undo/Redo and ⌘Z/⇧⌘Z save inverse edits. Editors save nonempty drafts on outside click/tool/library/document changes or quit, and Cancel/Escape discards. Notes excludes bare marks, FreeText and on-page images.
- Storage: atomic manifest/PDF writes under Application Support, managed copies independent of source file permissions, metadata schema check, load errors preserve existing files and block imports. Explicit export copy. Settings uses native UserDefaults. No source-file handles, web-data import, library removal or cloud sync.
- Design: one Apple Liquid Glass–inspired green/neutral palette, material cards, quiet gradients, serif headings and a Reduce Transparency fallback. System/Light/Dark are color modes of this single theme; no Classic/Studio selector. The library sidebar collapses during reading. The reader starts with the PDF and one compact tool row; independently toggle Pages/Outline or Notes when needed. Contextual editing controls appear for the selected annotation. Import/export and stars live in More page actions and native menus. Initial fit and Fit page use the whole page; manual zoom remains available.
- AI: home Ask Folio sheet offers saved per-paper conversation, selected-passage explanation when a reader selection exists, Simple Technical English and source-backed Problem/Approach/Finding overview. Codex CLI / GPT-6.1 Terra medium is default; Claude API is explicit. Requests start only on Send/Explain/Generate; Cancel or dismissal cancels. Chat uses a compact 12K map and bounded paper tools/web search on demand; overview uses distributed passages capped at 120K. Saved overviews restore without generation. Responses appear on completion with basic Markdown and clickable page/source links. No rendered LaTeX, token streaming, OpenReview analysis or concept graph. Generated sample contains only synthetic instructional text.

See [porting map](PORTING.md) for incomplete functionality and [evidence](TESTING.md) for what was actually tested.

## Native feature expansion (2026-11-14, built and unit-tested; no interactive GUI QA)

- Reader: debounced live search with all-match highlight and count, normalization (case, diacritics, whitespace, soft hyphen, hyphenated line breaks); ⌘F/⌘G/⇧⌘G/Return/Esc. Zoom ⌘+/⌘−/⌘0, Fit Width ⌘9, Fit Page ⌘8, zoom menu; view-only rotation ⌥⌘L/⌥⌘R restored before save/export. Per-paper zoom/fit/layout/rotation persist; single/continuous/two-page layouts; thumbnail navigator with current page, numbers and star. Bare ←/→ J/K Home/End G act only when PDFView is first responder; Go menu.
- Margin marks: color bars beside highlight/underline/note lines, merged/striped when nearby, note glyph; click selects/cycles/opens the note; hit-testing only on bars; never written to the PDF.
- Library: sort recent/added/title/author (persisted); chips All/Starred/With notes/Unread (unread = page 1); author search; hero progress bar. arXiv import sheet ⇧⌘I with explicit Download, progress, cancel and PDF validation before a managed copy. Drag-drop, Finder Open With, dock drop, multi-select open panel; rename, remove with confirmation (deletes only the managed copy), reveal in Finder, context menus.
- Notes: inspector grouped by page with search/color filter/inline edit/delete with undo bar; note image attachments in `<library>/NoteImages/<paperID>/`; draft autosave `Drafts/<paperID>.json` restored on reopen; ruled writing pages after the current page (⌥⌘N) or at end, undoable and exported.
- Assistant: multiple threads per paper in `Assistant/<id>.threads.json` (legacy history migrated); Claude API SSE streaming with tool loop, Stop ⌘. and Retry; Codex CLI completion-only; no fallback. Markdown/code blocks/LaTeX shown as Unicode text (not typeset); clickable page citations; Explain / Ask about selection prefill without sending. Offline skim (abstract, keywords, key sentences, reading time). Assistant/Reviews/Concept Map reachable from reader toolbar and Assistant menu (⌥⌘A/E/R/M).
- Design: Theme tokens FolioSpace/FolioRadius, folioCard/folioWell/folioSheetBackground, FolioHeader/FolioChip/FolioNotice/FolioSecondaryButtonStyle unify home, sheets, notes inspector and settings; empty states for library and reviews.

## AI in the reader right panel (2026-11-14; built and unit-tested, partial GUI QA)

Human request: bring the web AI features to the native app with polished UI, then reduce friction (no separate AI windows; follow the web UI). Supersedes the sheet-based AI text above.
- AI lives in the reader's right panel with an always-visible 44pt icon rail (Notes, Ask, Peer reviews, Concept map). Clicking an icon opens that section; clicking the open one collapses. Library Ask Folio opens the paper with Ask.
- Ask is inline chat: chat-history menu, new chat, provider and Simple Technical English options, one-click suggestions, Return sends, ⌘. stops, Retry banners, clickable page citations. A live PDF selection attaches as a removable passage chip with one-click Explain this passage.
- Assistant menu: ⌘J Ask About This Paper, ⌥⌘A Ask About Selection (prefill), ⌥⌘E Explain Selection (sends immediately, an explicit action), ⌥⌘G Paper at a Glance, ⌥⌘R Peer Reviews, ⌥⌘M Concept Map. PDF right-click on selected text: Explain with Folio AI / Ask Folio AI About Selection….
- Insights is a dedicated library destination with a paper picker, Read paper action, and Paper at a glance (saved source-backed Problem/Approach/Finding cards plus local abstract, keywords, key sentences and reading time (abstract extraction retains line boundaries to stop at numbered section headings)). Library row/card/continue-reading actions and ⌥⌘G open it. It never appears in the annotation sidebar. Browsing preserves the active PDF/position; source links explicitly open the inspected paper on that page. Leaving Insights cancels its generation.
- Requests still start only from explicit Send/suggestion/Explain/Generate/Find actions; no background calls.
- Fixes: Codex CLI now works natively (its `-c` TOML values were corrupted by escaped slashes), real Codex failure reasons are shown, and Claude web search `pause_turn` continues the turn.
- Not ported: web "Insights on selection" auto mode and the Skim highlight overlay (Explain is one click). A successful live provider answer is unverified; see [TESTING](TESTING.md).

- Provider switching: Codex CLI ⇄ Claude API from any AI panel header or Settings → AI assistant. Claude key saved to the login Keychain from Settings (environment `ANTHROPIC_API_KEY` takes priority); model Claude Sonnet 5.5 or Opus 5.5. Readiness checks use a non-interactive attributes-only Keychain query; only an explicit Claude request retrieves the secret, and successful unlocks are cached in memory until replacement/removal or process exit. Missing key → inline “Add Claude API Key…” prompt in Ask and a warning on the switch.
